# 实现与迁移差异

## 持久化边界

插件独立使用 `river_food_*` 表，与 Discourse User、Group、Notification 集成。图片经过类型检查、方向修正、移除元数据和尺寸压缩后存入插件媒体表；不依赖旧站上传路径。公开内容的图片可由游客查看，待审核投稿图片限作者和管理员。

写入命令在事务中采用请求指纹与幂等键；权限在查找缓存结果之前检查。对门店修改和审核加行锁，并比较版本。审核只合并相对申请前资料发生变化的字段，避免覆盖无关新修改。历史待审申请需要明确确认。

公开内容主体按文本渲染；关于页面使用 Discourse Markdown 清洗。上传仅允许 JPEG/PNG/GIF/WebP，限制像素数、输入大小、输出大小、请求频率和个人累计容量。来源链接仅允许 HTTP(S)。

## 有意保留或调整的行为

- 旧基础评分和顶层点评共同计算平均值，保留一位小数；回复不参与评分。
- 首页沿用旧推荐公式与六种排序，缺失图片仍计入历史照片数量以保持排序，界面标注缺图。
- 推荐随机种子在翻页时固定；可以手动换一批。目录使用显式分页，以支持稳定地址和历史返回。
- 体验标签使用旧版标记解析；同票标签沿用中文排序，首页展示前三项。
- 点赞以真实关联记录为准，不沿用可能失真的缓存计数；原始值完整存档供核查。
- 旧 GitHub 账号只保留署名及内容，无登录通道，无自动认领。
- 新版会员收藏存数据库，可随论坛备份；旧版浏览器收藏需要同源导出后手动导入。
- 匿名化保留去身份的贡献；删除账号隐藏其点评、推荐菜并清理用户媒体，保留社区门店基本资料。账号合并去重收藏、点赞等关联。
- 历史导入不创建通知；只读预览禁止通知投递。

## 上线检查

完成独立库导入与逐项核对后，再安排旧服务停写、最终导出、校验哈希、生产备份、插件部署、最终导入和浏览器验收。旧域名跳转与浏览器收藏导出入口属于正式切换步骤。两台共享数据库的 Web 必须使用相同插件版本与资源。
