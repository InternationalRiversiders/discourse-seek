# 私有测试验收 · 2026-09-21

本次只部署到隔离测试入口，旧觅电继续运行。正式切换需要重新停写、导出和核对当时的最新数据。

## 数据核对

共 6,238 项检查通过。旧代码的店铺归一化、标签解析、筛选和推荐排序作为独立对照，核对了：

- 130 家店铺的介绍、原始推荐语、人均、状态、位置、来源、时间与署名。
- 208 条店铺点评、9 条关于页面留言及父子回复、评分、标签和时间。
- 18 条点赞关系，21 条历史新店申请、5 条待审修改。
- 126 张可用图片；2 张在旧存储已缺失的图片保留引用和缺失标识。
- 34 个 GitHub 历史账号和 2 个已不存在的论坛账号保留历史署名，不创建登录账号。
- 5 种目录排序、14 组筛选条件、6 种发现页排序，及全部店铺的评分和汇总信息。

发现旧缓存点赞数与关联记录不一致的情况：店铺点评 1 条、关于留言 3 条。新版使用真实点赞关系计算，原始计数留存档案。历史导入不创建事件或通知。

## 测试

- 一次性数据库：7 个后端回归测试，77 条断言通过。
- 浏览器：目录模式、分页与返回、点评配图与标签、楼层回复、点赞和论坛通知、写入权限、推荐菜、会员和游客收藏、新店投稿与采纳、旧版本修改冲突确认、相册和分享卡片。
- 论坛共同侧栏及跨功能导航通过；深浅色主题、320/390/768/1440 像素宽度通过，无页面 JavaScript 异常。
- 真实数据测试库仅管理员访问且只读；写入请求被拒绝，130 家店铺和 5 条待审修改可正常查看。

浏览器同时覆盖有历史投稿的账号，防止投稿列表模板出现递归渲染。修改模板时避免将局部变量命名为 HTML 标签（例如 `p`）。

旧浏览器收藏属于用户设备数据，不在数据库导出范围；仍需旧域名同源导出和用户主动导入。
